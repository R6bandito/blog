# 夜间背景图目录

把夜间模式专用的背景图放进这个文件夹即可，其余逻辑已自动接好。

## 命名规范

```
night1.webp
night2.webp
night3.webp
...
```

（连续编号，从 1 开始；如果缺号，后面的图会跳过——比如放了 1、3 两张，只会用 night1）

## 图片建议

- **格式**：webp 最佳（jpg 也行，但体积大）
- **尺寸**：**2560×1440 以上**（横图），或和白天背景图同规格
- **数量**：5-8 张比较合适（和白天组一致）
- **风格**：夜色氛围——城市夜景 / 星空 / 夜晚的风景 / 深色抽象都行；
  月亮、灯光、夜色海面这类"一眼看出是夜晚"的效果最好
- **色调**：深色为主（因为暗色主题的整体基调是深色）

## 转换方法（如果是 png/jpg）

```
ffmpeg -i 原图.png -c:v libwebp -quality 80 night1.webp
```

## 生效时机

图片放好后告诉我（或自行重新生成站点），夜间模式下就会自动用这组图轮换；
**在放入图片之前，夜间模式会暂时沿用白天的背景图**（不会出错）。
