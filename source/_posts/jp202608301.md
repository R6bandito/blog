### ～と思う

含义：我心里想、觉得（我的想法，不一定说出口）

~这一部分叫「内文简体」，【思う・言う】叫作主句谓语，主句也可以变简体。

各时态 简体 / 敬体 完整对照表：

| 时态     | 敬体                   | 简体                   |
| -------- | ---------------------- | ---------------------- |
| 现在肯定 | ～と思います           | **～と思う**           |
| 过去肯定 | ～と思いました         | **～と思った**         |
| 现在否定 | ～とは思いません       | **～とは思わない**     |
| 过去否定 | ～とは思いませんでした | **～とは思わなかった** |

> 需要注意：不管后面是敬体「と思います」还是简体「と思う」，前面的从句必须用简体形！
>
> 名词・ナ形容词 在接续时简体肯定后面必须加 **だ**

接续：**简体形 + と思う**

用例

**动词・イ形容词（接续时直接简体）**：

- **雨が降ると思います**。（我觉得会下雨）
- **明日は暑いと思います**。（我觉得明天会很热）

**ナ形容词・名词 → 词＋だ＋と思います**：

- **李さんは静かな学生だと思います**。（我认为小李是一个文静的学生）
- **あれは静かだと思います**。（我觉得那里很安静）

注意：ナ形容词・名词接续时一定要加 だ。

**否定（简体否定，不加だ）**：

- **バスがこないと思う**。(我觉得公交车不会来)
- **雨が降らないと思います**。（我觉得不会下雨）

> 注意，と思う有人称限制。只能自己做主语！用于自身。
>
> 森さんは行くと思います。是绝对错误的❌

### ～と言う

说、讲（已经开口讲出来的话）。也用于第三人称转述。

各时态简体 / 敬体对照表：

| 时态     | 敬体                 | 简体                 |
| -------- | -------------------- | -------------------- |
| 现在肯定 | ～と言います         | **～と言う**         |
| 过去肯定 | ～と言いました       | **～と言った**       |
| 现在否定 | ～と言いません       | **～と言わない**     |
| 过去否定 | ～と言いませんでした | **～と言わなかった** |

接续：**简体形 + と言う**

与 と思う一样，ナ形容词・名词接续用于肯定接续时必须加 だ。否定接续时不加。

用例：

- **动词**：**田中さんは行くと言いました**。（田中先生说了要去）
- **イ形容词**：**高いと言った**。（（他）说很贵）
- **ナ形容词・名词** ：
  **彼は医者だと言いました**。（他说他是医生）
  **ここは静かだと言いました**。（他说这里很安静）
- **否定**：**こないと言った**。(（他）说了不来)

> 注意：と言う没有人称限制，谁都可以用。
>
> 例如：先日、私は行かないと言いました。(前些天我说过我不去)（翻旧账、回顾自己之前的发言）

### ～のです / ～んです

んです＝のです 的口语缩写。书面用于用 のです 更礼貌，平时口语用 んです 。

简体版：～のだ / ～んだ

**表示自己所陈述的内容与前面的对话相关联（上下文关联），常用于解释原因，理由。**

接续规则：

- 动词/イ形容词直接简体 + ～のです / ～んです.
- ナ形容词・名词简体 + な + ～のです / ～んです.

> ⚠一定要注意：名词 / 二类形容词**不能直接接んです，中间必须加な**。必须！

用法：

- 解释、说明原因、背景（最常用），用来给刚才发生的事补充背后理由。
  A：**どうして遅れたの**。为什么迟到了？
  B：**電車が遅れたんです**。（原因是）电车晚点了。

- 强调事实、把已知的事点明出来。
  **実は、私は日本に行ったことがあるんです**。其实啊，我去过日本的。

- 发问，带关心、探寻内情：～んですか。
  んですか ≠普通ですか。

  普通：**何を食べますか**。你要吃什么？（单纯提问）
  探寻内情：**何を食べるんですか**？（你怎么了 / 为啥要吃这个？）
  **どうしたんですか**。发生什么事了？（关心对方）

- 结果、发现。
  窓を開けたら、雨が降っていたんです。一打开窗，原来正在下雨。

敬体 ↔ 简体对照表:

| 礼貌形 (です・ます)    | 简体 (普通形)  |
| ---------------------- | -------------- |
| ～のです／～んです     | ～のだ／～んだ |
| ～のですか／～んですか | ～のか／～んだ |

口诀记忆： **无问无背景，不用んです； 有因有内情，就用んです。**

什么时候该用？

开口之前自问一句：我这句话是不是用来解释前面某件事 / 回应对方的疑问 / 带出隐藏内情？

是 → 可以用 んです；否，只是冷不丁抛出一条新消息 → 别用んです。

口语中区分不是那么明显，但是书面和考试中不能乱加。
