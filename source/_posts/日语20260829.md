### 日语动词分类

| 类型                 | 特征                                                 | 例子                                           |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------- |
| **五段动词（一类）** | 词尾在「う」段上变化，不是一段动词的都是五段         | 書く、読む、買う、待つ、話す、泳ぐ、死ぬ、帰る |
| **一段动词（二类）** | 以「る」结尾，且「る」前一个假名在**い段**或**え段** | 食べる、見る、起きる、寝る、考える(おしえる)   |
| **サ変动词（三类）** | 「する」及「～する」                                 | する、勉強する、連絡する                       |
| **カ変动词（三类）** | 只有「来る」一个                                     | 来る                                           |

> *注意：有些动词虽然以「る」结尾、前面是い/え段，但是**五段动词**，如「帰る」「入る」「知る」「走る」「要る」，需要单独记。*

### 变形总览表

| 变形名称         | 五段（書く）                | 一段（食べる） | サ変（する） | カ変（来る） |
| ---------------- | --------------------------- | -------------- | ------------ | ------------ |
| 辞书形（基本形） | 書く                        | 食べる         | する         | 来る         |
| ます形           | 書きます                    | 食べます       | します       | 来ます       |
| て形             | 書いて                      | 食べて         | して         | 来て         |
| た形             | 書いた                      | 食べた         | した         | 来た         |
| ない形           | 書かない                    | 食べない       | しない       | 来ない       |
| ば形             | 書けば                      | 食べれば       | すれば       | 来れば       |
| 命令形           | 書け                        | 食べろ         | しろ         | 来い         |
| 意志形           | 書こう                      | 食べよう       | しよう       | 来よう       |
| 可能形           | 書ける                      | 食べられる     | できる       | 来られる     |
| 被动形           | 書かれる                    | 食べられる     | される       | 来られる     |
| 使役形           | 書かせる                    | 食べさせる     | させる       | 来させる     |
| 使役被动形       | 書かせられる （書かされる） | 食べさせられる | させられる   | 来させられる |

具体变形细则：

**基本形**：动词本身现在的样子。也是动词简体形式的现在肯定时态表达。

------

**ます形**：

| 类型     | 规则                       | 例子                |
| -------- | -------------------------- | ------------------- |
| 五段动词 | 词尾「う段」→「い段」+ます | 書く→書きます       |
| 一段动词 | 去掉「る」+ます            | 食べる→食べます     |
| サ变     | する→します                | 勉強する→勉強します |
| カ变     | 来る→来ます                | 来る→来ます         |

用于敬体句子，接「たい」「ながら」「方」等。例句：**歩きながら話します**。（一边走一边说）

------

**て形**：

| 类型           | 规则          | 例子                                  |
| -------------- | ------------- | ------------------------------------- |
| 一段动词       | 去掉「る」+て | 食べる→食べて                         |
| サ变           | する→して     | する→して                             |
| カ变           | 来る→来て     | 来る→来て                             |
| 五段・く       | く→いて       | 書く→書いて                           |
| 五段・ぐ       | ぐ→いで       | 泳ぐ→泳いで                           |
| 五段・う/つ/る | →って         | 買う→買って、待つ→待って、帰る→帰って |
| 五段・ぬ/ぶ/む | →んで         | 死ぬ→死んで、遊ぶ→遊んで、読む→読んで |
| 五段・す       | す→して       | 話す→話して                           |

> 注意：行く是五段动词，但て形是「行って」，不是「行いて」！

用于：

- **动词接续**：朝ご飯を食べて、学校へ行く。（吃了早饭去学校）
- **请求**：ちょっと待ってください。（请等一下）
- **表示进行时**：本を読んでいます。（正在读书）
- **表示状态的持续**：結婚している。（已婚）

------

**た形**：

和「て形」完全一样，把「て/で」换成「た/だ」。

| 类型           | 规则      | 例子                                  |
| -------------- | --------- | ------------------------------------- |
| 一段动词       | 去る＋た  | 食べる→食べた                         |
| サ变           | する→した | した                                  |
| カ变           | 来る→来た | 来た                                  |
| 五段・く       | く→いた   | 書く→書いた                           |
| 五段・ぐ       | ぐ→いだ   | 泳ぐ→泳いだ                           |
| 五段・う/つ/る | →った     | 買う→買った、待つ→待った、帰る→帰った |
| 五段・ぬ/ぶ/む | →んだ     | 死ぬ→死んだ、遊ぶ→遊んだ、読む→読んだ |
| 五段・す       | す→した   | 話す→話した                           |

用于：

- **过去式**：昨日映画を見た。（昨天看电影了）
- **表示完成的状态**：もう食べた？（吃了吗？）
- **表示经历**：行ったことがある。（去过）
- **条件**：駅に着いたら、知らせてください（到了车站请告诉我）

------

**ない形（否定形）**：

学校语法中属于**未然形**。未然＝还没有发生、未实现，是日语动词变形的一个中间词干形态，本身不能单独结尾，后面必须接东西：接否定「ない」、接意志「う・よう」、接被动・使役等等。

例如：書く　＋　ない　＝　書かない。

👉「書か」这一截，就是未然形！

ない形变形规则：先变未然形，而后加上否定助动词ない。

| 类型     | 规则                       | 例子                             |
| -------- | -------------------------- | -------------------------------- |
| 五段动词 | 词尾「う段」→「あ段」+ない | 書く→書かない；買う→買**わ**ない |
| 一段动词 | 去掉「る」+ない            | 食べる→食べない                  |
| サ变     | する→しない                | しない                           |
| カ变     | 来る→来ない                | 来ない                           |

> 注意：
>
> 词尾是「う」的动词，变成「わ」而不是「あ」，如「買う→買わない」！
>
> 「ある」的ない形是「ない」，而不是「あらない」！记清楚，很容易错。

用于：

- **否定**：今日は働かない。（今天不工作）
- **用于部分接续**：
  なければ(必须，不得不) ——> 宿題をしなければなりません。(必须做作业)
  なくても(不必) ——> 明日、来なくてもいいです。(明天不来也行)
  ないと思う(我认为不.....) ——> 値段は高くないと思います。(我认为价格不贵)
