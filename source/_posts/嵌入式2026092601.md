#### 前言

本篇文章用于记录一些Linux系统中的常用操作命令。Linux的命令系统是十分强大和复杂的，为了能够熟练进行系统操作，在这里归档一些常用命令以及常用参数，便于随时查看。如果需要更多更细节的一些操作命令，请自行查阅手册。

------

#### 文件与目录操作命令

- `pwd`：**显示当前所处路径**

  没有任何参数，单纯用来看自己当前处于什么位置。

  ```bash
  user:~/work$ pwd
  /home/Yukirin/work
  ```

- `cd`：**切换工作目录**

  ```bash
  cd /home/user/project   # 进入绝对路径
  cd project              # 进入相对路径
  cd ..                   # 返回上一级
  cd ../..                # 返回上两级
  cd ~                    # 回到家目录（等价于 cd）
  cd -                    # 回到上一次所在目录
  ```

  这里要注意一下：`cd -` 不是进入上一级目录，而是类似于出栈撤回的操作。例如当前处于家目录，使用`cd /user/project/subdir` 跳转后，使用 `cd -` 回到的不是 `/user/project`，而是跳转之前的家目录。

- `ls`：**列出当前目录下内容**

  ```bash
  ls                  # 简单列出
  ls -l               # 长格式：权限、链接数、所有者、大小、时间、名字
  ls -a               # 显示隐藏文件（以 . 开头）
  ls -h               # 人类可读大小（配合 -l）
  ls -lh              # 最常用组合
  ls -alh             # 显示所有文件 + 长格式 + 易读大小
  ls -t               # 按修改时间排序（新的在前）
  ls -r               # 反向排序
  ls -S               # 按大小排序（大的在前）
  ls -R               # 递归列出子目录
  ls -d */            # 只列出目录本身，不展开内容
  ls -i               # 显示 inode 号
  ```

  实际开发中，最常用的组合是 `ls -alh` ，能够应对90%的使用场景。在一些Linux的发行版（例如我这个Ubuntu 26.04）会将该命令重定义为 `ll`，敲命令时直接使用`ll`更方便。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~$ ll
  total 76
  -rw------- 1 Yukirin Yukirin  5426 Sep 25 16:51  .bash_history
  -rw-r--r-- 1 Yukirin Yukirin   220 Sep 18 18:54  .bash_logout
  ....
  
  Yukirin@DESKTOP-8BFBE1K:~$ ls -alh
  total 76K
  -rw------- 1 Yukirin Yukirin 5.3K Sep 25 16:51  .bash_history
  -rw-r--r-- 1 Yukirin Yukirin  220 Sep 18 18:54  .bash_logout
  ....
  ```

  可使用`type`命令检查是否有绑定，如果没有，自己绑定一个就可以了。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~$ type ll
  ll is aliased to `ls -alF'  
  ```

  我这里定义为 `-alF` ，给文件名加了类型标记。你也可以自己组合参数进行定义。

- `tree`：**树状图显示目录结构**

  ```bash
  tree                # 递归显示
  tree -L 1           # 只显示 1 层
  tree -L 2           # 显示 2 层
  tree -d             # 只显示目录
  tree -a             # 显示隐藏文件
  tree -h             # 显示大小
  ```

  `tree`命令可能并没有自带，如果使用`tree`提示找不到该命令，那么使用下列命令进行安装

  ```bash
  sudo apt install tree
  ```

  `tree`命令效果如下，在查看文件和目录时还是很方便的。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~$ tree
  .
  ├── C_Test
  │   └── new.c
  ├── Untitled
  ├── WSL-Neovim排查记录.md
  ├── snap
  │   └── glow
  │       ├── 90
  │       ├── common
  │       └── current -> 90
  ```

- `mkdir`：**目录创建**

  ```bash
  mkdir test                  # 创建单个目录
  mkdir dir1 dir2 dir3        # 创建多个目录
  mkdir -p a/b/c              # 递归创建多级目录
  mkdir -m 755 test           # 创建时指定权限
  ```

  这里讲一下：父目录不存在，递归创建时必须带上 `-p` 参数。直接使用 `mkdir dir1/dir2/dir3` 是创建不了的

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~$ mkdir dir1/dir2/dir3
  mkdir: No such file or directory
  
  Yukirin@DESKTOP-8BFBE1K:~$ mkdir -p dir1/dir2/dir3
  Yukirin@DESKTOP-8BFBE1K:~$ tree
  ├── dir1
  │   └── dir2
  │       └── dir3
  ```

  关于创建时指定权限：这里的 755 是**八进制权限码**，每一位对应一类用户的使用权限。

  7-5-5 三位分别代表：

  | 位置    | 对应对象   | 英文       |
  | :------ | :--------- | :--------- |
  | 第 1 位 | 文件所有者 | user (u)   |
  | 第 2 位 | 所属组     | group (g)  |
  | 第 3 位 | 其他人     | others (o) |

  3位数字的各自计算方法：

  | 数字 | 权限  | 含义      |
  | :--- | :---- | :-------- |
  | 0    | `---` | 无权限    |
  | 1    | `--x` | 只可执行  |
  | 2    | `-w-` | 只可写    |
  | 3    | `-wx` | 可写+执行 |
  | 4    | `r--` | 只可读    |
  | 5    | `r-x` | 可读+执行 |
  | 6    | `rw-` | 可读+可写 |
  | 7    | `rwx` | 全部权限  |

  所以755在这里表示：

  ```bash
  7        5        5
  rwx      r-x      r-x
  所有者    组       其他人
  ```

  需要时直接查表算就行了。其实`mkdir`在指定权限时也支持符号写法：

  ```bash
  mkdir -m u=rwx,g=rx,o=rx test    # 等价于 755
  mkdir -m a=rwx test              # a=所有人，等价于 777
  ```

  这些写法都是等价的，符号写法规律很明显，不用查表算数字，我比较喜欢这种方法；不过数字写法速度快，背下常规几种组合之后直接用就行。

- `rmdir`：**空目录删除**

  ```bash
  rmdir test                  # 删除空目录
  rmdir -p a/b/c              # 递归删除空目录（a/b/c 都为空时）
  ```

  这个命令只能删除空目录，若目录内部有文件将删除失败。删除带文件的目录应该用下文的`rm -r` 命令，`rmdir`不是很常用，了解一下。

- `touch`：**文件创建**

  ```bash
  touch file.txt              # 创建空文件
  touch file1 file2           # 创建多个
  touch -c file.txt           # 文件不存在时不创建
  touch -a file.txt           # 只更新访问时间
  touch -m file.txt           # 只更新修改时间
  touch -t 202609260830 file  # 指定时间戳：YYYYMMDDhhmm
  ```

  这里讲一个有意思的点：`touch`原意其实并不是创建文件，touch的英文是触摸，原本设计的目的是修改文件的时间戳。不过当touch的目标文件不存在时，会先创建一个新文件。后续慢慢的就都使用该命令来创建文件了。

- `rm`：**删除文件或目录**

  ```bash
  rm file.txt                 # 删除文件
  rm -i file.txt              # 删除前询问
  rm -f file.txt              # 强制删除，不询问
  rm -r dir                   # 递归删除目录
  rm -rf dir                  # 递归强制删除（危险！）
  rm -v file.txt              # 显示删除过程
  ```

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~/work$ rm -i a.out
  rm: remove regular file 'a.out'? n
  Yukirin@DESKTOP-8BFBE1K:~/work$ ll
  total 36
  -rwxrwxr-x 1 Yukirin Yukirin 16608 Sep 25 16:41 a.out*
  ```

  这里要提醒一下：`rm -rf /` 是删除整个root跟目录的自杀式命令，永远不要执行。现在的发行版基本都会拒绝`rm -rf /`这个命令，但是最好自己在上层加入一些防误操作保护，不要依赖内部实现。

  `-v`参数会在终端打印删除了什么。如果需要知道具体删除了哪些文件，可以带上该参数。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~/work$ rm -v -i a.out
  rm: remove regular file 'a.out'? y
  removed 'a.out'
  ```

  可以给`rm`命令加上别名，带上确认与反馈机制，防止误操作。

  ```bash
  alias rm='rm -i'
  ```

  上面我们提到，`rm -r` 可以用于删除带文件的目录，日常使用删除目录的命令基本都是使用这个。

  这里关于 `rm -rf` 的使用要注意一下：`rm -rfv dir1/dir2/dir3` 执行这行命令之后只会删除`dir3`以及`dir3`的所有子级目录！而不是摘掉`dir1/dir2/dir3`整棵树，`dir1/dir2` 都还在。如果想要摘掉 `dir1/dir2/dir3` 整棵树应该使用 `rm -rfv dir1`。这个地方不弄清楚很容易用错。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~$ tree dir1/
  dir1/
  ├── dir2
  │   ├── dir3
  │   └── nana.lua
  └── lala.lua
  
  2 directories, 3 files
  Yukirin@DESKTOP-8BFBE1K:~$ rm -rfv dir1/
  removed 'dir1/dir2/nana.lua'
  removed 'dir1/dir2/dir3'
  removed directory 'dir1/dir2'
  removed 'dir1/lala.lua'
  removed directory 'dir1/'
  Yukirin@DESKTOP-8BFBE1K:~$ find dir1
  find: ‘dir1’: No such file or directory
  ```

- `cp`：**复制文件和目录**

  ```bash
  cp file1 file2              # 复制文件
  cp file1 dir/               # 复制到目录
  cp -r dir1 dir2             # 递归复制目录
  cp -a dir1 dir2             # 归档复制，保留权限、时间、链接
  cp -p file1 file2           # 保留权限和时间
  cp -i file1 file2           # 覆盖前询问
  cp -u file1 file2           # 仅当源更新时才复制
  cp -v file1 file2           # 显示过程
  ```

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~/dir1$ cp -vp /home/Yukirin/work/tcp_client.c ../dir1/
  '/home/Yukirin/work/tcp_client.c' -> '../dir1/tcp_client.c'
  Yukirin@DESKTOP-8BFBE1K:~/dir1$ ls /home/Yukirin/dir1/
  dir2  tcp_client.c
  ```

  `-i`参数可以在即将发生覆盖行为时提醒用户。`cp`默认覆盖是静默无声的，某些情况下可能会导致误冲刷重要文件，所以建议使用别名将 `cp -i` 封装起来使用。

  ```bash
  Yukirin@DESKTOP-8BFBE1K:~/dir1$ cp -iv tcp_client.c tcp_back.c
  cp: overwrite 'tcp_back.c'? y
  'tcp_client.c' -> 'tcp_back.c'
  ```
